# 隐私与数据边界

## 项目处理的数据

本项目可在本机读取已解密的微信 SQLite 归档，并生成 JSON、CSV 和自包含 HTML。这些产物可能包含聊天内容、联系人名称、微信号和群聊信息，应按敏感个人数据保护。

## 不应提交到 Git 的内容

- `config.json` 及其中的真实路径、微信号和别名。
- `output/`、`dist/`、`build/` 中的任何产物。
- `*.db`、`*.sqlite*`、`*.csv`、`*.jsonl` 和微信归档目录。
- 真实聊天截图、导出页面、Obsidian 私人库和安装包。

`.gitignore` 已屏蔽上述常见类型，但提交前仍应执行 `git status` 和 `git diff --cached` 人工复核。

## 数据使用原则

- 仅处理你有权处理的数据，并遵守所在地法律及平台规则。
- 看板默认离线生成；不要将真实产物发布到公网。
- 需要截图或示例时，使用完全虚构的数据，并复核页面源码中是否仍有真实信息。

## 第三方工具

本仓库不附带数据解密或提取器源码。若使用第三方工具准备 SQLite 归档，请单独审核其许可证、来源、安全性和使用条款。
